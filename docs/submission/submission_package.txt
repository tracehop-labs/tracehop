# TRACEHOP — PROJECT REPORT & APPLICATION ARCHITECTURE

1. PROJECT DESCRIPTION
TraceHop is an institutional-grade on-chain wallet intelligence and forensic graph platform designed specifically for Web3 token launches on Robinhood Chain, Solana, and EVM ecosystems.

In decentralized trading, retail participants face extreme information asymmetry. Malicious actors create token launches that appear organic on the surface, but are actually controlled by coordinated sybil sniper rings, disguised funding relays, and centralized creator wallets.

TraceHop dismantles this deception by analyzing the initial transaction block graph of any token in real time. It reverse-traces deposit paths across multi-hop intermediary wallets back to common parent roots (such as CEX hot wallets or mixer addresses), analyzes wallet age variance, buy-timing synchronization, and gas-source overlap, and produces an objective, real-time forensic verdict: THREAT (Cabal / Rug Hazard) vs SAFE (Organic & Distributed).

2. CORE CAPABILITIES
- Sub-Second Forensic Interrogation: Deep scan executed within milliseconds over streaming Server-Sent Events (SSE) across 9 progressive stages.
- Multi-Hop Graph Resolution: Traces funding ancestry 3+ hops backward to expose disguised buyer clusters.
- Launch Buy Uniformity Scoring: Evaluates standard deviation, mean buy size, and same-block clustering to flag automated sniper scripts.
- Hold-to-Access Gating (x402): Token-gated institutional tier requiring 50,000 $ARDRILL balance verification directly on-chain, with 3 free anonymous scans for casual users.
- MCP & Bot Readiness: Built-in Model Context Protocol (MCP) server endpoints allowing AI agents and Telegram bots to query live forensic reports during autonomous trading workflows.

3. END-TO-END APPLICATION FLOW (USER & SYSTEM WORKFLOW)
[Step 1: Ingestion & Gating]
- User opens https://tracehop-web.vercel.app.
- User selects Robinhood Chain and inputs a token contract address (e.g., preset $ARDRILL: 0x37c68202303082e5c7c279a9c6f646786a94116a62cd75d1f7650f86bfeadfde).
- GateKeeper middleware checks connection: verifies EVM wallet balance for 50,000 $ARDRILL via RPC, or decrements local anonymous free scan quota (3 free).

[Step 2: SSE Forensic Pipeline Execution]
The engine initiates a Server-Sent Events (SSE) stream, dispatching 9 real-time milestones:
1. Deployer Located: Identifies creator EOA, contract creation block, and initial liquidity funding.
2. First 20 Buyers Buffered: Isolates the earliest pool swap transactions.
3. Funding Graph Built: Recursively queries transfer ancestry for each buyer.
4. Wallet Clusters Resolved: Groups addresses sharing gas or fund origins.
5. Behavior Similarity Scored: Compares swap timing deltas, gas prices, and amount variance.
6. Known Wallets Cross-Referenced: Matches addresses against CEX deposit databases and flagged sybil rings.
7. Deployer History Pulled: Queries creator's past launches (graduated, rugged, or inactive).
8. Bundle Detection: Flags atomic bundle scripts (Jito / Flashbots / private mempool buys).
9. Verdict Generated: Compiles the Unified Asset Intelligence Model (UAIM) payload.

[Step 3: Interactive Visual Forensics Report]
The frontend receives the UAIM payload and dynamically renders 4 forensic accordion panels:
- Panel 1: Funding Relation Graph — Interactive 2D/3D SVG constellation map with Sonar radar rings, Bezier curves connecting buyers to parent hubs, and an active node inspector.
- Panel 2: Launch Buy Uniformity — Bar distribution chart tracking buy size deviation, same-block clustering, and uniformity percentage.
- Panel 3: Deployer Profile History — Bar breakdown of past deployer outcomes (Launch / Died / Grad / Rug) and reputation score (0.0 - 1.0).
- Panel 4: Behavior Analysis Verdict — Macro risk header with ShieldAlert (THREAT in rose-red) or ShieldCheck (SAFE in emerald green), confidence score (0-100%), risk signal tags, and 4 core metrics (Parent Share %, Fresh Wallets %, Insider Share %, Total Holders).

[Step 4: Autonomous Agent & Telegram Querying]
Users and AI agents can query the exact same forensic intelligence on Telegram via @tracehop_bot or programmatically via `/api/scan?address=<CA>` and MCP tools.
